# Examensarbete KPI Guide

Use this with `examensarbete_kpi_template.csv`.

## 1. Open the template
- Open `examensarbete_kpi_template.csv` in Excel.
- Keep formulas in rows marked `CALC` and `OUTPUT`.

## 2. Fill only INPUT rows
- Number of customers by plan
- Prices per plan
- Monthly costs
- New/lost customers
- ARR multiples

## 3. Read key results
- `MRR (summary)`
- `ARR (summary)`
- `Gross margin %`
- `CAC (summary)`
- `Churn % monthly`
- `Estimated valuation range low/high`

## 4. Build three scenarios for report
Create 3 copies of the file:
- `scenario_conservative.csv`
- `scenario_base.csv`
- `scenario_high.csv`

Change only INPUT values in each copy and compare outputs.

## 5. What to include in your YH report
- Table with MRR/ARR/CAC/Churn/Gross margin per scenario.
- Short method note: assumptions, data source, and limitation.
- Explain valuation range as indicative (not exact market value).
