## 6. EXCLUDED MATERIAL — Vad som INTE ska inkluderas

| Material | Anledning | Handling |
|----------|-----------|----------|
| **Enskilda avlopp-föreskrifter** | Utanför scope (inte miljöbeslut) | DELETE |
| **Processhandlingar (1000+ PDF utan juridisk betydelse)** | Kommunikation, inte juridik | QUARANTINE |
| **Administrativa manualer för tjänstemän** | Vägledning, inte juridik | QUARANTINE |
| **Duplicerade versioner av samma lag** | Data-debt | CONSOLIDATE |
| **Tomt lagrade versioner (< 50 KB)** | Skräp | DELETE |
| **Test-PDFer eller uploads** | Development-artifact | DELETE |

## 8. JURIDISK DOMÄN MAPPING FÖR RAG

**Vid chunking och embedding ska varje juridisk enhet taggas med:**

```typescript
type LegalChunkMetadata = {
  domain: "FOUNDATION" | "REGULATORY" | "MUNICIPAL" | "PRECEDENT";
  subdomain: "SFS" | "NFS" | "HVMFS" | "BFS" | "ABVA" | "COURT_DECISION";
  authority: "Riksdagen" | "Naturvardsverket" | "HaV" | "Boverket" | "Kommun" | "Domstol";
  legalArea: "miljöbalken" | "vatten" | "avfall" | "naturskydd" | "planering" | "artskydd" | string;
  municipality?: string;  // Om relevant (ABVA)
  court?: string;         // Om relevant (domstolsbeslut)
  applicableFrom: Date;   // Då denna juridik började gälla
  applicableTo?: Date;    // Om upphävd
};
```

## 9. EXKLUDERINGSKRITERIER (för "enskilda avlopp")

Om dokumentet innehåller **NÅGOT** av dessa, kategorisera som "enskilda avlopp" och QUARANTINE:

- "Enskild avloppsanläggning"
- "Mindre avloppsanläggning < 2000 PE" (PE = personenheter)
- "Septic tank" eller "filterbädd"
- "Småhusavlopp"
- "Privat avlopp"
- "Bortledning av husspillning"
- "Plogering av avlopp" (gamla systems)

**EXCEPT:** Om dokumentet också behandlar större kommunala system eller principiell miljörätt, behåll det.
