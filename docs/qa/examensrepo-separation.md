# utvecklingsrepo separation

Ett separat utvecklingsspar har arkiverats i katalogen `archive/projekt/utvecklingsrepo/`.

## Syfte

1. Separera utvecklingssammanstallning fran aktiv produktdrift.
2. Kor verifiering forst, rapport efter godkand kvalitetsgate.
3. Behall full sparbarhet via evidensindex och dataset-freeze.
4. Minska konflikt- och brusytan i huvudrepo genom att samla historiskt utvecklingsmaterial i arkiv.

- Huvudfil: `archive/projekt/utvecklingsrepo/README.md`
- Runbook: `archive/projekt/utvecklingsrepo/docs/runbook.md`
- I/O-kontrakt: `archive/projekt/utvecklingsrepo/docs/io-contracts.md`
