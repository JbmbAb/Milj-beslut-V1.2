# Examensrepo separation

Ett separat examensspar har etablerats i katalogen `examensrepo/`.

## Syfte
1. Separera examenssammanstallning fran produktdrift.
2. Kor verifiering forst, rapport efter godkand kvalitetsgate.
3. Behall full sparbarhet via evidensindex och dataset-freeze.

## Snabbpekare
- Huvudfil: `examensrepo/README.md`
- Runbook: `examensrepo/docs/runbook.md`
- I/O-kontrakt: `examensrepo/docs/io-contracts.md`
- Pipeline scripts: `examensrepo/tools/*`
