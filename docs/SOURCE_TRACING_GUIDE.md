# Source Tracing Guide (Källspårning)

**Status:** 🟢 IMPLEMENTED IN ALL GENERATORS

---

## 🎯 OVERVIEW

**Källspårning** (Source Tracing) är ett kritiskt krav som speglar:

1. **Transparens** – Var kommer varje punkt från?
2. **Auditerbarhet** – Vilken AI-version? Vilken data-source-version?
3. **Tillförlitlighet** – Hur självsäker är AI om detta (0-100)?

Implementerad i:

- ✅ **Project Plan Generator**
- ✅ **Logistics Generator**
- ✅ **Permit Application Generator**

---

## 🏗️ IMPLEMENTATION

### SourceTracing Interface

```typescript
interface SourceTracing {
  source: string; // Data source identifier
  timestamp: string; // ISO 8601 date
  version: string; // Source/AI model version
  confidence?: number; // 0-100, for AI-generated content
}
```

### Source Types

| Source             | Version            | Confidence | Example                 |
| ------------------ | ------------------ | ---------- | ----------------------- |
| `GEMINI_AI`        | `gemini-1.5-flash` | 75-95      | AI-generated analysis   |
| `POSTGIS`          | `14.x`             | 100        | Geographic data         |
| `SNI_REGISTRY`     | `2024`             | 100        | Industry classification |
| `LANTMATERIET`     | `2024`             | 100        | Property information    |
| `SGU`              | `2024`             | 100        | Soil & groundwater data |
| `NATURVÅRDSVERKET` | `2024`             | 100        | Environmental laws      |
| `SWEDAC`           | `2024`             | 100        | Lab accreditation       |
| `SMHI`             | `2024`             | 100        | Weather/climate data    |

## 💾 DATABASE SCHEMA

When saving to database, include full source tracking:

```prisma
model ProjectPlan {
  id           String
  projectId    String
  plan         Json  // Full plan with embedded sourceTracking
  sourceTracking Json[] // Array of SourceTracing objects
  externalSources String[]
  createdAt    DateTime
  updatedAt    DateTime
}

model PermitApplication {
  id           String
  projectId    String
  application  Json  // Full application with embedded sourceTracking
  sourceTracking Json[]
  externalSources String[]
  createdAt    DateTime
  updatedAt    DateTime
}
```

## 🎯 CONFIDENCE SCORING

### High Confidence (85-100%)

- Regulatory requirements (100% – law-based)
- Geographic data from PostGIS (100% – measurements)
- SNI classifications (100% – official registry)
- Lab recommendations (95% – SWEDAC data)

### Medium Confidence (70-84%)

- Risk analysis (75-85% – AI-assessed)
- Budget estimates (75-80% – AI-calculated)
- Mitigation measures (75-85% – AI-suggested)

### Low Confidence (<70%)

- Uncommon situations
- Complex multi-factor scenarios
- User should review carefully
